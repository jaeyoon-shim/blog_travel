## B. 문체 따라하기 (커밋 `2ff3571..00870c2`)

**접근법 A — LLM 문체 프로파일 추출.** 원문 통째 주입(표절 위험) 폐기, "규칙+예시" 주입으로 전환.

- `StyleAnalyzer.__init__(config=None)` + `_scrape`(스크래핑 분리) + `extract_profile`(LLM/폴백 라우팅)
- `_extract_profile_llm` — temp=0, json_object, "확실한 것만" (환각 방지) + `_normalize_profile`(상한: 어미 6, 예시 2)
- 무료모드/키없음 → `_profile_from_regex` 폴백(`extracted_by="regex_fallback"`)
- 스크래핑 텍스트 <200자 → `warning` 사용자 노출 (조용한 품질저하 금지)
- `_style_context` 재작성 — 규칙+예시 1~2문장만, 원문 문단 통째 금지(회귀 테스트로 고정)
- `/api/style` config 주입 + warning 응답, 기존 `state["style_analysis"]` 슬롯 재사용(generate 배선 무변경)
- UI `doStyle()` 추출 톤·경고 표시

## E. 네이버 SEO·핵심태그 강화 (커밋 `5dc7392..b7e8f80` + `addbc7f`)

**사용자 결정: "코드가 검증·강제" + "코드 추출+AI 병합".**

- `analyze(count=10)` — 상위 블로그 방문 3→10개(성공분만 집계)
- `_extract_keywords` staticmethod — 불용어(KEYWORD_STOPWORDS)·검색어 자신 제외
- `extract_core_tags(analysis, region)` — 실측 빈도+지역명 조합 3~5개, LLM 없음(결정적)
- `merge_tags(ai, core, cap=10)` — 핵심 태그 선두 보장, 공백/# 정규화 중복제거
- `seo_check(post, analysis, region)` — 제목 키워드/분량 60%/태그 지역명 3종 경고(발행 안 막음)
- `_naver_context` **"지도 삽입 필수" 기존 결함 수정**(불변식 충돌 → 회귀 테스트)
- `generate_drafts` 배선 + 편집 화면(renderS4) ⚠️ SEO 점검 배지
- **E2E에서 발견·수정**: `/api/drafts` 화이트리스트 직렬화에 `seo_warnings` 누락(`addbc7f`)
