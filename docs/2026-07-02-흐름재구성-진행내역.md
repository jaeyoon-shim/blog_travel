## 2. 단계 순서 재구성 (`19d9e8b`)
사용자 기대 순서: 계정설정 → 사진업로드 → 일자별기획 → 기획수정 → 게시글작성 → 게시글피드백 → 발행.
실제와 불일치(설정이 1번이 아니고, 일자별기획/기획수정이 한 화면). 아래로 재번호화:

| STEP | 화면 | render 함수 | 비고 |
|---|---|---|---|
| 1 | ⚙️ 설정 | `renderSettings` | 기존 ⚙️ 별도 아이콘 제거, 스텝바에 편입 |
| 2 | 📸 업로드 | `renderS1` | |
| 3 | 🗂 계획검수 | `renderS2` | 내부 **"📋 일자별 기획"(읽기전용)/"✏️ 기획 수정"(편집)** 탭 분리 (`switchPlanTab`, `renderPlanView`) |
| 4 | 🤖 AI생성 | `renderS3` | |
| 5 | ✏️ 편집 | `renderS4` | =게시글 피드백 |
| 6 | 🚀 발행 | `renderS5` | |

- `render()` 디스패치 맵: `{-1:프로필선택, 1:설정, 2:S1, 3:S2, 4:S3, 5:S4, 6:S5}`.
- 프로필 자동로드(기존 프로필 有)면 설정 스킵하고 `go(2)` 업로드로 직행(회귀 없음).
- 신규/오류 시 `go(1)` 설정으로.
