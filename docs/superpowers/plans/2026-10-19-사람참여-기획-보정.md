# 사람 참여 기획·중간 보정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사람이 글 기획(브리프)부터 참여하고, 본문을 쓰기 전 목차를 승인하고, 쓴 뒤에는 섹션 단위로 다시 쓰기·고정·블록 편집 저장으로 보정할 수 있게 한다 — 확정 제목·고정 섹션·브리프·목차 편집은 어떤 재생성도 조용히 덮지 않는다.

**Architecture:** 2단 생성(A안). `core.py`에 네트워크 없는 순수함수(브리프 병합·목차 정규화·프롬프트 조각·섹션 분할/교체/이식)를 모듈 함수로 추가하고, `TravelBlogGenerator`에 `generate_outline`(목차 1회 호출, JSON 모드)·`revise_section`(섹션만 KEEP 토큰 잠금 재작성)을 더한다. 기존 본문 파이프라인(`generate_drafts` → `_call_ai` → 사진·지도·경로 코드 조립)은 그대로 재사용하고 `brief_block`/`outline_block` 문자열 두 개만 프롬프트에 꽂는다. `app.py`는 기존 관례(백그라운드 스레드 + `state["progress"]` + `/api/status` 폴링, 파일 영속)로 목차·섹션·블록 라우트를 더하고, UI는 `static/index.html` 단일 인라인 스크립트에 1단계 브리프 카드·2단계 일차 브리프·3단계 목차 화면·섹션 툴바·블록 자동저장을 넣는다.

**Tech Stack:** Python 3 (venv), Flask, OpenAI Python SDK(`chat.completions.create`), pytest(monkeypatch, `app.test_client()`), 인라인 Vanilla JS(`startPoll(cb)`), Node(`vm.Script` 파싱 검증), gstack `/browse`(실렌더).

## 스펙 해석 — 구현하며 정한 것 (변경 시 이 절부터 고칠 것)

1. **순수함수 위치**: 스펙 §5의 7개 순수함수 + `normalize_brief`/`group_place_names`/`outline_section_hint`/`section_files`/`_url_count`는 **`core.py` 모듈 함수**(앱·생성기 공용). `normalize_outline(raw, place_names, keyword="")`는 has_keyword 계산용 선택 인자를 더했다(스펙 시그니처 호환).
2. **`splice_locked` 반환값**: `(html, kept_keys)` 튜플. 이식 못 한 고정 섹션을 완료 메시지로 밝히기 위함(불변식 5 "조용히 덮지 않음"). 추가로 **섹션 사진 구성(`data-files` 시퀀스)이 바뀌었으면 이식하지 않는다** — 옛 섹션을 되붙이면 "방문 순서 = 사진 순서"(불변식 3)가 깨지기 때문.
3. **섹션 경계**: `<h2 …>`마다 1섹션, 키 = `data-place` 값(없으면 h2 텍스트, 중복이면 `" #2"`). 섹션 시작은 h2를 감싼 헤더 div(`_SECTION_HEADER_DIV`, 400자 창 rfind) → **경로 카드는 직전 섹션 꼬리**에 속한다(`_insert_route_guides`가 목적지 헤더 div 앞에 꽂음). `__tips__`는 마지막 h2 뒤 `TRAVEL TIPS`/`여행 꿀팁`/`다음 여행기에서` 중 첫 마커의 래퍼 div부터 끝까지(꿀팁+아웃트로). 꿀팁·아웃트로를 설정에서 끈 글은 `__tips__`가 없을 수 있다.
4. **섹션 재작성 잠금 범위**: 기존 `_find_asset_spans`(figure·위키박스·경로카드)에 더해 `<!--MAPCARD/MAPLINK-->` 마커(URL 포함 — 기존 `revise_draft`는 이걸 잠그지 않음), 장소 헤더 div(h2 = 섹션 키, 안의 별점·가격 줄 포함), 사진 캡션, 별점·가격 줄, 코스 요약 `🚶`을 KEEP 토큰으로 잠근다(`_protect_section`). 실데이터 8개 초안 전 섹션에서 잠금 후 텍스트에 `<h2`·URL 0 확인.
5. **`revise_section` 반환값**: `(new_post, "")` 또는 `(None, 사유)` — 사유를 progress error 메시지로 보여준다(스펙 §6.4).
6. **동시 실행 409 대상**: `POST /api/outline/<gi>`, `POST /api/revise_section`, `POST /api/lock_section`. 기존 `/api/generate`엔 409를 추가하지 않는다(전역 락 F4는 별건).
7. **`use_outline`**: `/api/generate`는 `use_outline: true`일 때만 승인 목차를 쓴다(없거나 미승인이면 400). `use_outline` 없으면 목차 미사용("목차 없이 바로 쓰기" 탈출구). **`/api/generate_all`은 승인 목차가 있는 일차에 자동으로 목차를 쓴다** — 안 그러면 전체 생성이 확정 제목을 `optimize_title`로 덮는다(불변식 5). 브리프는 모든 생성 경로에 주입.
8. **재생성의 고정 섹션 보존**: `/api/generate`·`/api/generate_all`·기존 `/api/revise`(전체 피드백 재작성)도 고정 섹션을 이전 HTML에서 되붙인다(`_carry_locked`). `/api/revise`는 `edited_blocks`도 무효화(`revise_draft`가 `dict(post)` 복사라 그대로 두면 옛 블록이 살아남음).
9. **`has_saved_drafts` 정정**: 지금은 `drafts/` 폴더 존재로 판정(app.py:408) → 목차 파일만 있어도 "초안 있음"이 되어 3단계가 빈 편집 화면으로 열린다. `group_*.json` 존재로 판정하도록 고친다(Task 7).
10. **목차 화면 진입**: 3단계 생성 화면(일차 목록)의 주 버튼을 "📋 선택한 Day 목차부터 쓰기"로 두고, 기존 단일 생성은 "목차 없이 바로 생성"으로 남긴다. 초안이 있는 일차는 편집 화면 섹션 카드의 "📋 목차 보기/수정"으로 간다. (현재 프론트는 일차별이 아니라 "초안이 하나라도 있으면 편집 화면" 전역 판정 — `renderDraftStep`, index.html:748-755 — 이라 일차별 자동 분기는 하지 않는다.)
11. **블록 편집 저장 범위**: `PUT /api/blocks/<gi>/<di>` 본문 `{blocks, title}` — 편집 화면 제목 입력도 같이 저장(지금은 새로고침 시 소실). 재작성 확인창은 **직접 편집이 있을 때만**(`edited` 또는 미저장) 띄운다.

def normalize_outline(raw, place_names, keyword=""):

def outline_prompt_block(outline):
    """승인 목차 → `[승인된 목차 — 반드시 따름]` 조각. 목차가 없으면 ""."""
    if not isinstance(outline, dict) or not outline.get("sections"):
        return ""
    lines = ["", "[승인된 목차 — 반드시 따름. 글쓴이가 검토·확정한 글 설계입니다]"]
    if outline.get("intro_hook"):
        lines.append(f"- 인트로 첫 문단 방향: {outline['intro_hook']}")
    lines.append("- 장소 섹션(순서·이름 변경 금지):")
    for i, s in enumerate(outline["sections"], 1):
        bits = []
        if s.get("gist"):
            bits.append(f"요지: {s['gist']}")
        if s.get("emphasis"):
            bits.append(f"강조: {s['emphasis']}")
        ln = s.get("length") or "보통"
        if ln != "보통":
            bits.append(f"분량: {_LENGTH_RULE.get(ln, ln)}")
        lines.append(f"  {i}. {s.get('place', '')}" + (" — " + " / ".join(bits) if bits else ""))
    if outline.get("tips"):
        lines.append("- 꿀팁 영역에 반드시 담을 내용: " + " / ".join(outline["tips"]))
    if outline.get("outro"):
        lines.append(f"- 아웃트로 방향: {outline['outro']}")
    return "\n".join(lines) + "\n"


def outline_section_hint(outline, key):
    """섹션 재작성용 — 해당 섹션의 승인 목차 요지만 조각으로. 없으면 ""."""
    if not isinstance(outline, dict):
        return ""
    if key == "__intro__":
        body = outline.get("intro_hook") or ""
    elif key == "__tips__":
        parts = list(outline.get("tips") or [])
        if outline.get("outro"):
            parts.append("마무리: " + outline["outro"])
        body = " / ".join(parts)
    else:
        sec = next((s for s in outline.get("sections") or [] if s.get("place") == key), None)
        body = ""
        if sec:
            bits = [f"요지: {sec['gist']}" if sec.get("gist") else "",
                    f"강조: {sec['emphasis']}" if sec.get("emphasis") else ""]
            body = " / ".join(b for b in bits if b)
    return f"[이 섹션의 승인된 목차]\n{body}\n" if body else ""

        di = html[win:pos].rfind(_SECTION_HDR)
        if di >= 0:
            pos = win + di
        if starts and pos <= starts[-1][0]:
            pos = m.start()
        starts.append((pos, key))
        last_h2_end = m.end()
    tail = None
    for mk in _TAIL_MARKERS:
        mi = html.find(mk, last_h2_end)
        if mi >= 0 and (tail is None or mi < tail):
            tail = mi
    if tail is not None:
        # 텍스트 마커는 래퍼 div 안쪽이다 → 래퍼 여는 태그로 되짚는다(lessons 07-06 #3)
        win = max(last_h2_end, tail - 400)
        di = html[win:tail].rfind('<div')
        if di >= 0:
            tail = win + di
    bounds = [(0, "__intro__")] + starts
    if tail is not None:
        bounds.append((tail, "__tips__"))
    out = []
    for i, (pos, key) in enumerate(bounds):
        end = bounds[i + 1][0] if i + 1 < len(bounds) else len(html)
        out.append((key, html[pos:end]))
    return out


def replace_section(html, key, new_chunk):
    """key 섹션만 new_chunk로 교체. key가 없으면 None(호출부가 실패 처리)."""
    secs = split_sections(html)
    if key not in [k for k, _ in secs]:
        return None
    return "".join(new_chunk if k == key else c for k, c in secs)


def section_files(chunk):
    """섹션 안 figure data-files의 원본 파일명 시퀀스(순서 유지)."""
    out = []
    for v in re.findall(r'data-files="([^"]*)"', chunk or ""):
        out.extend(f for f in v.split("|") if f)
    return out


def splice_locked(old_html, new_html, keys):
    """고정 섹션(keys)을 old_html에서 new_html로 이식 → (html, 실제 이식된 키 목록).
    새 HTML에 키가 없거나, 섹션의 사진 구성(data-files 시퀀스)이 달라졌으면
    이식하지 않는다 — 옛 사진을 되붙이면 '방문 순서 = 사진 순서' 불변식이 깨진다."""
    old = dict(split_sections(old_html))
    kept, out = [], []
    for k, chunk in split_sections(new_html):
        if k in (keys or []) and k in old and section_files(old[k]) == section_files(chunk):
            out.append(old[k])
            kept.append(k)
        else:
            out.append(chunk)
    for k in keys or []:
        if k not in kept:
            logger.warning(f"⚠️ 고정 섹션 이식 생략: {k} (새 초안에 없거나 사진 구성이 바뀜)")
    return "".join(out), kept


def _url_count(s):
    """data URI를 걷어낸 뒤 https?:// 개수(base64 안 우연한 'http' 오탐 방지 — lessons 08-17(2) #7)."""
    s = re.sub(r'data:[a-zA-Z0-9.+/-]+;base64,[A-Za-z0-9+/=]+', '', s or "")
    return len(re.findall(r'https?://', s))

        re.compile(r'<p style="text-align:center;margin:4px 0 20px;color:#999;'
                   r'font-size:\.85em">[^<]*</p>'),          # 사진 캡션(📍 장소명)

        re.compile(r'<p[^>]*>\s*🚶[^<]*</p>'),                # 코스 요약(_insert_course_summary)
    )

    def _protect_section(content):
        """섹션 HTML → ([KEEP_n] 토큰 텍스트, 자산 리스트). _protect_assets와 같은
        토큰 규약(_restore_assets로 복원)이되, 마커·헤더·캡션·별점·코스요약까지 잠근다."""
        content = content or ""
        spans = list(TravelBlogGenerator._find_asset_spans(content))
        for pat in TravelBlogGenerator._SECTION_EXTRA_ASSET_PATS:
            spans += [(m.start(), m.end()) for m in pat.finditer(content)]
        spans.sort()
        merged = []
        for s, e in spans:
            if merged and s < merged[-1][1]:
                merged[-1] = (merged[-1][0], max(merged[-1][1], e))
            else:
                merged.append((s, e))
        assets, out, prev = [], [], 0
        for s, e in merged:
            out.append(content[prev:s])
            out.append(f"[KEEP_{len(assets) + 1}]")
            assets.append(content[s:e])
            prev = e
        out.append(content[prev:])
        return "".join(out), assets

        content = (post or {}).get("content") or ""
        if not instruction:
            return None, "지시가 비어 있습니다"
        secs = dict(split_sections(content))
        if key not in secs:
            return None, "해당 섹션을 찾을 수 없습니다"

            "아래는 여행 블로그 글의 한 섹션(HTML 조각)이다. 사용자 지시에 맞게 이 섹션의 문장만 다시 써라.\n"

                model=self.model,

    """재생성 결과에 이전 초안의 고정 섹션을 같은 순번 초안끼리 이식한다.
