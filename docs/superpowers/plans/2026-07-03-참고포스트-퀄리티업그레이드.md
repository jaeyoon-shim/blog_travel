## T1. 사진 콜라주 합성 (I1) — core.py

1. `TravelBlogGenerator._compose_collage(paths, out_dir=None) -> str|None` (staticmethod 불가 —
   로거만 쓰면 staticmethod 권장):
   - 입력 2장: EXIF 방향 보정(`ImageOps.exif_transpose`) → RGB 변환 → 높이 1080px 정규화
     (비율 유지) → 가로 이어붙임(사이 8px 흰 여백) → JPEG q85로 임시파일 저장, 경로 반환.
   - 실패(파일 없음/PIL 에러) 시 None 반환(호출부가 단독 삽입 폴백).
   - 3장 이상은 호출부에서 2장씩 청크(홀수 마지막 1장은 단독).
2. `_insert_photos_with_map` 수정: `place_groups`에서 같은 장소 사진 ≥2장이면 2장 청크로
   `_compose_collage` → 성공 청크는 `_photo_html(collage_path, display, gps, show_map=마지막청크)`
   한 번만 호출. [PHOTO:] 태그 처리(1단계)와의 정합: 같은 장소의 태그들 중 첫 태그 위치에
   콜라주를 넣고 나머지 태그는 제거(사진 중복 방지). `inserted`에 원본 file_name 전부 등록.
3. `_photo_html`: `display`를 캡션 라인으로 항상 출력(현행은 show_map일 때만 📍 라인).
   캡션 = 가운데 정렬·회색(#999)·.85em, 📍는 지도 폴백 라인에만 유지.
4. 테스트: 임시 이미지 2장(세로/가로 혼합) 합성 → 크기·비율 검증, 1장/실패 폴백,
   [PHOTO:] 태그 2개→콜라주 1개+태그 잔존 0.

## T2. 구글맵 장소 OG 카드 (I2) — core.py + posters.py

1. core.py `_resolve_poi`: 채택된 POI의 `place_id`를 반환 dict에 포함 →
   photo_result `r["place_id"]`로 저장(채택 실패/무료 모드는 키 없음).
   ⚠ plan/project.json 직렬화는 photo_result 통째 저장이라 추가 작업 없음 — 확인만.
2. core.py `_photo_html(..., map_card_url=None)`: show_map이고 `map_card_url` 있으면
   📍 라인 대신 `<!--MAPCARD:{url}|{display}-->` 마커 + 미리보기용 📍 라인
   (마커는 주석이라 미리보기에 안 보임 — 발행 시에만 카드로 변환).
   URL 생성: `https://www.google.com/maps/place/?q=place_id:{pid}`.
3. posters.py `html_to_blocks`: `<!--MAPCARD:url|display-->` 정규식 →
   `{"type":"map_card","url":url,"label":"↑↑ {display} 위치 ↑↑"}` 블록.
   마커가 카드로 변환되면 같은 구간의 📍 텍스트 라인은 `_skip` 처리(중복 방지).
4. posters.py `NaverSeleniumPoster._paste_map_card(url, label)`:
   ```
   a. _clipboard_set_text(url) → Ctrl+V → Enter
   b. .se-oglink 출현 폴링 (0.5s 간격, 최대 8s) — driver.find_elements
      (본문 iframe 컨텍스트 주의: 기존 _paste_text와 동일 컨텍스트 사용)
   c. 성공: Enter로 다음 문단 → label 텍스트 붙여넣기(가운데 정렬은 기존 _set_center_align
      상태 활용) → Enter
   d. 실패: Shift+Home 선택 → Delete로 URL 문단 제거 → "📍 {display}" 텍스트 폴백
   e. 예외 무시(발행 계속) — 카드 실패가 발행을 막으면 안 됨
   ```
   블록 디스패치 `elif btype == "map_card":` 추가.
5. 테스트(네트워크 없음): 마커→블록 변환, place_id 없는 결과에 마커 미생성,
   기존 map_link 회귀 없음.

## T3. 프롬프트 실용정보 + 코스 요약 (I3·I4) — core.py

1. 프롬프트(장소 소개 규칙)에 추가:
   - "각 장소마다 '어떤 사람에게 추천하는지' 문장 1개를 자연스럽게 포함"
   - "가격·영업시간 등 실용 정보는 [장소별 필수 지시]·영수증·실측 참고에 **명시된 것만** 서술.
     자료에 없는 숫자를 지어내지 말 것" (개수 강요 금지 — lessons #3)
   - "한 단락은 2~4문장, 경험담 → 실용정보 → 추천 순"
   - f-string 중괄호 이스케이프 주의({{ }}).
2. `_insert_course_summary(content, groups_or_plan)`:
   - stop 이름 순서로 `A → B → C` 문자열. 8개 초과 시 사진 수 상위 8개만(원 순서 유지).
   - `<p style="text-align:center;...">🚶 {요약}</p>`을 첫 `<h2>` 직전에 삽입
     (h2 없으면 본문 맨 앞). URL 없음.
   - 생성 라우트에서 `_insert_photos_with_map` 뒤에 호출.
3. 테스트: 요약 순서/축약, h2 앞 삽입 위치, 프롬프트에 "URL 금지" 규칙 잔존 assert.

## T4. 태그 확장 (I5) — core.py
